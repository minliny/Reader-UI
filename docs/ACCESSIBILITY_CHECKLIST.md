# Reader 跨端无障碍验收清单（HarmonyOS / Android / iOS）

> [!NOTE]
> 本清单适用于 **HarmonyOS**、**Android (TalkBack)** 与 **iOS (VoiceOver)** 现行主线与重建端，接替已随旧 demo 退役的 `IOS-REF-06`。
> 静态检查与黄金快照仅能覆盖部分结构约束，**设备级读屏聚焦、听感播报与焦点恢复必须在实际模拟器、真机或录屏中独立取证**，禁止以单元测试或截图 PASS 替代。

---

## 1. 色彩对比度与非颜色提示

- [ ] **正文对比度**：App 日/夜主题（`#FF1D1B18` on `#FFF4EFE6` / `#FFECE8E0` on `#FF151715`）及全部 **8 套阅读纸底**的正文与背景对比度满足 WCAG AA `>= 4.5:1`；页眉页脚 `chromeMeta`、次级文字 `--rd-muted` 满足可读对比度（大字号 `>= 3:1`，常规字号 `>= 4.5:1`）。
- [ ] **控件边界与状态图标**：描边、开关轨道、选中态边框、图标着色在日/夜模式下均有清晰可见边界；夜间图标不保留未适配的暗墨色（如旧 `#2D4A3E` / `#1F3528` 须映射为浅松绿或浅墨）。
- [ ] **非颜色单一编码**：书源检测状态（L1–L5 通过/警告/失败）、选中态、禁用态、书架缓存标签、危险操作除色彩区分外，必须同时具备文字标签、图标外形（轮廓/填充）或无障碍状态值（`selected` / `disabled`）。
- [ ] **阅读状态栏独立对比**：阅读页系统状态栏前景与背景跟随当前纸底 `statusForeground` / `statusBackground`，不出现浅底白字或深底黑字。

---

## 2. 触控命中区与前景互斥

- [ ] **最小命中目标**：所有可交互动作（含书架 `···`、朗读胶囊 `94–96×24` 及其内部暂停钮、目录返回/排序钮、控制岛抓手与步进钮）可点击命中区均满足 **`>= 44×44`（dp / pt / vp，对应 `ReaderDesignMetrics.minimumActionTarget`）**。
- [ ] **视觉与命中分离**：扩展命中区不得放大图标本身绘制尺寸；相邻按钮（如顶部胶囊栏多动作、控制岛进度区左右切章钮）命中区不得重叠误触。
- [ ] **前景互斥与冒泡隔离**：
  - `ReaderRecoveryNotice` 在自身边界内拦截触摸冒泡，边界外交还底层页面；
  - 当控制岛、换源抽屉、目录面板、确认弹窗或原生 Web 登录页占用前景时，底层 `RecoveryNotice` 及底页内容**必须退出绘制、命中检测与无障碍遍历**，前景关闭后恢复。

---

## 3. 动态字号与窄屏弹性布局

- [ ] **缩放策略分离**：
  - 系统 UI 文本随系统字体缩放（Android FontScale / iOS Dynamic Type / HarmonyOS `scalePolicy=system`）；
  - 阅读正文由已保存的阅读 appearance 字号/行距独立控制，**禁止将系统字号叠乘到阅读正文上**。
- [ ] **排版度量对齐**：Android Compose 文本显式设置 `PlatformTextStyle(includeFontPadding = false)` 与 `LineHeightStyle`，跨端显式传入 `fontSize` 与 `lineHeight`，防止大字号下卡片与列表行被额外上下留白撑爆。
- [ ] **大字号与 `< 360` 窄屏防溢出**：
  - 书架列表卡在超大字号或 `< 360` 窄屏下，标题最多 2 行，作者/已读章/最新章单行省略，封面高度受控且按钮保持完整可点；
  - 换源抽屉、设置行、下载列表在大字号下允许行高随内容增长或进入统一垂直滚动流，禁止截断关键操作按钮（如「重试」「确认」「取消」「删除」）。

---

## 4. 读屏语义与焦点流（TalkBack / VoiceOver / HarmonyOS ScreenReader）

- [ ] **语义标签与状态播报**：
  - 所有纯图标按钮（返回、搜索、筛选、更多、`+`、朗读/自动翻页控制、关闭 `×`）均提供明确、无内部代号的本地化无障碍标签（禁止朗读 `TOK_*` 或内部 ID）；
  - 开关、分段控件、选中项、禁用项正确暴露 `checked` / `selected` / `disabled` / `busy` 语义角色与当前值。
- [ ] **装饰元素隐藏**：分割线、装订线装饰、无封面卡片内部装饰线条、纯装饰配图与阴影层对无障碍树隐藏（`importantForAccessibility = no` / `.accessibilityHidden(true)`）。
- [ ] **模态焦点陷阱与焦点恢复**：
  - 打开控制岛（Quick/Full）、底部 Sheet（换源/目录/操作单）、确认 Dialog 时，读屏焦点自动移入弹层首个可聚焦标题/控件，并禁止划屏穿透到底层被遮挡页面；
  - 关闭弹层或返回上一页后，焦点准确恢复到原触发按钮或目标页首，不丢失到屏幕顶端以外。
- [ ] **短反馈与异步播报**：
  - 短反馈按 `FRAMEWORK.md` 调用非打断式无障碍播报（HarmonyOS `announceForAccessibilityNotInterrupt` / Android / iOS 对应礼貌级播报），**不抢夺当前输入焦点**；
  - 错误提示仅播报用户可理解的简明结论，严禁朗读内部异常类名、堆栈、URL 凭据或调试 JSON。
- [ ] **系统返回与手势替代**：依赖侧滑、边缘返回、下拉书签或上拉下一章的交互，在读屏开启时均存在可聚焦的等价点击入口或标准无障碍动作（例如控制岛内书签按钮、目录切章按钮、漫画章末点击提示条）。

---

## 5. Reduce Motion 与视觉休眠

- [ ] **统一减动效降级**：开启系统「减少动态效果」时，路由转场、控制岛展开/收起、Sheet 进出、书签回弹统一退化为 **`120ms` 轻淡入**（去除位移、缩放与 `380ms` 播放胶囊飞行轨迹）。
- [ ] **业务语义不丢失**：开启减动效后，短反馈 `2000ms`（换源 `2200ms`）停留、去重、未决操作确认、取消及失败恢复语义保持完全一致；开启后再关闭减动效，不重放已完成的旧动画。
- [ ] **循环动效休眠**：朗读微波形、自动翻页呼吸点、加载指示器在切后台、锁屏、被前景弹层遮挡或处于暂停态时立即停止帧驱动。

---

## 6. 分层验收记录模板

| 验收层级 | 验证内容 | 允许的结论范围 |
| --- | --- | --- |
| **源码 / 静态检查** | 命中区常量 `>= 44`、图标/标签覆盖、减动效分支、前景互斥谓词 | 仅证明源码规则存在，不代表读屏聚焦或对比度实机通过 |
| **黄金快照 / UI 树** | 日/夜/大字号/窄屏静态无截断、无重叠 | 不代表连续动画、焦序或语音播报通过 |
| **模拟器 / 真机读屏实测** | TalkBack / VoiceOver / 鸿蒙读屏逐页遍历、聚焦、播报、焦点恢复与系统返回 | 须独立记录设备型号、OS 版本、输入样本与录屏/日志证据 |
