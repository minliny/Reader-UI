# Paper Flow Motion Language

状态：设计方向草案，不代表当前 demo、合同或三端实现已经完成迁移
适用范围：Reader UI demo、iOS、Android、HarmonyOS 的产品动效设计
更新时间：2026-07-11

## 1. 定位

Reader 的动效语言命名为 **纸面流动（Paper Flow）**。

> 内容像纸一样稳定，工具沿上下文自然流动；操作跟随手指，所有运动最终安静地退回内容之后。

Reader 是长时间阅读工具。动效的职责是解释状态、层级、来源和操作结果，而不是制造独立的视觉表演。

## 2. 基本原则

1. **内容不漂移**：正文、书名、章节和阅读位置不得因无意义的装饰动画移动。
2. **来源可追踪**：新界面从触发它的位置或所属边缘出现，关闭时沿反方向返回。
3. **操作必须跟手**：拖拽、翻页、滑块和控制条由手势进度直接驱动。
4. **层级决定运动**：同层状态原位变化，跨层界面才产生空间位移。
5. **越接近正文，运动越轻**：阅读正文最安静，阅读工具其次，管理页面可以更明确。
6. **结束必须稳定**：每次运动都要收敛到可继续交互、无歧义的稳定状态。
7. **可随时中断**：新的用户意图优先于正在播放的动画。

## 3. 动效家族

### 3.1 墨触 Ink Response

用于按钮、图标、列表行、书籍卡片、Chip、Toggle 和 Tab 的即时反馈。

- 按下时轻微压缩或降低表面亮度，不改变布局和热区。
- 松手后快速恢复；若产生状态变化，直接衔接状态形变。
- 选中通过颜色、描边或局部填充稳定显现，不使用弹跳确认。
- Press 60-80ms，Release 100-120ms，Select 120-160ms。
- 缩放下限 0.97-0.985，不使用 overshoot。

### 3.2 纸页流转 Page Flow

用于页面 push/pop、内容详情、章节切换和进入阅读器。

- 新页面按语义方向进入，旧页面只做轻微退让。
- 前景运动明显、背景运动较弱，形成浅层空间关系。
- 返回严格逆转进入方向；replace 不得伪装成 push。
- 打开详情时背景退让约 4%-8%。
- 页面位移建议为容器宽度的 8%-18%，避免整屏长距离飞行。
- Push/Pop 220-280ms，内容替换 160-200ms，阅读器进入 260-320ms。

### 3.3 边缘工具 Edge Tools

用于 Sheet、目录、换源、筛选和侧边工具。

- 工具从其所属边缘出现，关闭时沿反方向收回。
- 背景不缩小，只允许轻遮罩或焦点降低。
- 临时工具出现时不改变无关内容的排版结果。
- 小型工具层 180-220ms，大型 Sheet 240-300ms。
- 遮罩透明度建议 12%-22%，不使用弹跳。

### 3.4 锚点迁移 Anchor Morph

用于 TTS、自动翻页、下载、同步和其他持续任务，是 Paper Flow 的标志性动效家族。

- 同一任务改变位置时保持身份连续，不消失后重新出现。
- 尺寸变化以稳定锚点为基准。
- 文本、图标和进度局部更新，容器不整体闪烁。
- TTS 与自动翻页切换时保留容器，只转换内部身份。
- 进入/退出 180-240ms，锚点迁移 240-320ms，内容更新 100-160ms。
- 关键状态最多允许一次不超过 1.03 的轻微脉冲。

### 3.5 手势牵引 Direct Pull

用于翻页、阅读进度、亮度、滑杆和可拖动面板。

- 手势阶段完全跟手，不使用预设时长动画。
- 越界使用渐增阻力，不突然截断。
- 释放后根据距离和速度共同决定完成或回退。
- 建议完成阈值为 35%-45%；高速滑动可降低距离阈值。
- Snap 140-220ms，最多一次轻微回弹，不允许连续振荡。

### 3.6 内容沉降 Content Settle

用于加载完成、搜索结果、网格/列表切换、排序、筛选、空状态和错误恢复。

- 内容在原位置重新组织，不使用页面级滑入。
- 旧内容先降低存在感，新内容再稳定显现。
- 列表重排尽量保留用户关注项和滚动位置。
- 大批量列表不做逐项长时间 stagger。
- 内容替换 140-200ms，列表重排 180-240ms，骨架退出 120-160ms。
- 若使用 stagger，每项间隔 12-20ms，总延迟不超过 120ms。

## 4. 统一节奏

产品只使用五档语义时长，页面不得新增私有毫秒值。

| 等级 | 时长 | 用途 |
| --- | ---: | --- |
| Instant | 0ms | reduced motion、同步状态提交 |
| Touch | 80ms | 按下、局部即时反馈 |
| Quick | 140ms | 选择、图标、局部内容更新 |
| Standard | 220ms | 页面、Sheet、状态替换 |
| Emphasis | 300ms | 阅读器进入、锚点迁移、方向重排 |

## 5. 统一缓动

- **Enter**：快速启动、柔和落位。
- **Exit**：轻柔启动、快速离开。
- **Move**：两端平稳，适合位置迁移。
- **Snap**：快速收束，用于手势释放。

全局不使用 bounce；不把明显弹簧作为默认风格；不允许持续 overshoot。品牌感来自连续性和锚点关系，而不是夸张弹性。

## 6. 层级决策表

| 关系 | 动效方式 |
| --- | --- |
| 同一组件状态变化 | 墨触反馈，不移动布局 |
| 同一页面内容变化 | 内容沉降，原位替换 |
| 同层页面切换 | 短距离纸页流转 |
| 父级进入子级 | 子级向前，父级轻微退让 |
| 临时工具覆盖内容 | 从所属边缘出现 |
| 持续任务改变位置 | 锚点迁移 |
| 用户直接拖动 | 手势牵引 |
| 系统环境变化 | 保留内容锚点后重新排布 |

## 7. 阅读场景纪律

- 正文不做呼吸、漂浮或循环动画。
- 翻页不得改变排版结果，不使用强拟物翻书。
- 临时工具出现时正文不缩放、不整体移动。
- TTS 高亮连续移动，避免整段闪烁。
- 自动翻页提示不得周期性抢夺注意力。
- 章节跳转优先保证位置确认。
- 除必要的运行状态外，不允许无限循环动画。
- 用户开始滚动或翻页时，非必要动画立即停止。

## 8. Reduced Motion

Reduced Motion 不是简单删除全部反馈：

- 空间动效降级为短交叉淡变或瞬切。
- 直接操控继续跟手，但缩短释放后的 Snap。
- 状态反馈保留颜色、描边和明暗变化，去除缩放和位移。

## 9. 品牌识别

Paper Flow 的四个识别点：

1. **纸面稳定**：正文与核心内容不乱动。
2. **边缘出具**：工具从所属边缘出现。
3. **锚点连续**：持续任务不凭空消失或重生。
4. **触控牵引**：直接操作严格跟手。

品牌表达：

> 纸面不动，工具流动；内容安静，操作有回应。
