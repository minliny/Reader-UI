# Paper Flow Icon System

状态：设计方向草案，不代表当前图标资产或动效合同已经完成迁移
依赖：[Paper Flow Motion Language](./PAPER_FLOW_MOTION_LANGUAGE.md)
更新时间：2026-07-11

## 1. 定位

Reader 图标是纸面上的工具符号，不是独立表演的动画角色。

> 图标本身保持清楚、稳定、克制；动效只解释触发、状态变化、方向和任务连续性。

图标的产品辨识度来自统一轮廓、留白、内部状态变化和任务路径，而不是为每个图标制作互不相关的动画。

## 2. 基础视觉体系

### 2.1 风格

- 默认采用温和、精确的线性图标。
- 选中态使用局部填充或线面结合，不把所有图标整体改为实心。
- 几何结构清楚，允许细微的人文感，但不使用手绘抖动。
- 圆角克制，避免过度可爱化。
- 外轮廓稳定，状态变化优先发生在内部结构。

### 2.2 网格与线宽

| 尺寸 | 画板 | 主图形区 | 线宽 |
| --- | --- | --- | --- |
| 常规 | 24 x 24 | 20 x 20 | 1.75px |
| 紧凑 | 16 x 16 | 独立绘制 | 1.5px |
| 状态图标 | 32/48 | 独立绘制 | 按比例校准 |

- 24px 图标使用 2px 安全区，视觉重心靠近 12 x 12。
- 小尺寸必须独立绘制，不直接缩放 24px 资产。
- 强调态线宽最多 2px；同尺寸不得混用多套线宽。
- 默认使用 round cap 和 round join，内部小结构可适当收紧圆角。

### 2.3 外稳内动

状态图标尽量保留至少 50% 的原轮廓：

- 网格/列表：外框保持，内部结构重排。
- 收藏：书签轮廓保持，内部由空心转填充。
- 播放/暂停：容器保持，三角形变为双竖线。
- 下载完成：下载路径收束为勾。
- 同步完成：同步路径保持，内部生成完成标记。

不能匹配的局部使用短交叉淡变，不允许整个图标无关联地替换。

## 3. 静态状态

### 默认态

- 单色线性、中等对比度、无大面积填充。
- 用于静止工具和未选中导航。

### 选中态

- 外轮廓基本保持，内部增加墨迹填充、局部面或品牌色。
- 不通过整体放大表示选中。
- 图标与文字共同变色，但不叠加多种夸张效果。

### 强调态

仅用于运行中的 TTS/自动翻页、下载/同步、错误、危险操作和主要阅读动作。运行中与选中态必须同时具备形状区别，不能只依赖颜色。

### Disabled

- 降低对比度，保持轮廓可辨认。
- 不播放动效。
- 不能只降低透明度到无法识别。

## 4. 图标动效家族

### 4.1 Ink Tap 触碰

- Press 时图标与容器整体缩放至 0.96-0.98，并轻微加深。
- 容器可出现低透明度墨迹面，不改变按钮尺寸与热区。
- Press 60-80ms，Release 100-120ms。
- 若触发状态变化，释放直接衔接状态变形。
- 禁止旋转、上下跳动、强光晕和弹跳恢复。

### 4.2 Ink Morph 状态变形

用于收藏、显示/隐藏、展开/收起、播放/暂停、网格/列表、锁定/解锁和日夜模式。

- 保留图标身份、重心和线宽。
- 简单旋转 140-180ms，路径变形 160-220ms，复杂线面变化不超过 240ms。
- 动画完成后立即稳定，不播放第二次确认动画。

### 4.3 Directional Turn 方向转向

- 箭头只解释方向，不额外表达成功。
- 展开箭头旋转 90 或 180 度。
- 返回方向与页面运动一致。
- 120-180ms，无弹性拉伸和 overshoot。

### 4.4 Ink Fill 墨迹填充

用于书签、收藏、Tab、单选、多选、阅读模式和来源启用状态。

- 外轮廓保持稳定，填充从内部、底部或中心显现。
- 取消选中沿反方向退回线性态。
- 120-180ms，填充与颜色变化同步。
- 禁止爆炸粒子、彩纸、光晕和填充后的二次弹跳。

### 4.5 Task Flow 任务流动

只用于真实持续任务：下载、同步、加载、TTS、自动翻页、缓存和内容解析。

- 能显示真实进度时不使用无限循环。
- 运动沿既有内部路径发生，外轮廓不循环缩放。
- 页面失焦或任务进入后台后降低运动强度。
- 建议周期 900-1400ms，不低于 700ms。
- 下载表现为箭头下沉与进度闭合；同步表现为双向路径推进；TTS 使用低幅声波；自动翻页使用页边缘或进度刻度推进。

### 4.6 Settle to Done 完成沉降

1. 运行轨迹停止。
2. 路径收拢至稳定位置。
3. 内部生成完成标记。
4. 状态色短暂增强后静止。

总时长 180-260ms。禁止跳动、抖动、烟花或重复播放。

### 4.7 Flow Interrupted 错误断流

- 运行轨迹停止并形成小型断点。
- 内部转为感叹号或重试箭头，颜色切换为错误色。
- 必须强调时只允许一次 2-3px 短促横移。
- 不闪烁、不持续抖动，错误原因必须由文字解释。

## 5. 导航图标

- 底部导航采用“同轮廓、局部填充”的选中体系。
- 旧图标内部填充退出，新图标内部填充进入。
- 两者不同时放大；图标与指示器使用同一 140-180ms 节奏。
- 页面内容切换可以稍慢，但相对图标延迟不超过 40ms。
- 不使用线性图标与无关联实心图标的直接替换。

## 6. 阅读器图标

- 阅读器图标比管理页面更细、更安静。
- 默认低对比度，进入对应交互状态后才提高可见度。
- 翻页、目录、字体、亮度、书签使用简单单义图形。
- TTS 与自动翻页必须具有不同轮廓，不能只用颜色区分。
- 运行状态通过内部变化表达，整个图标不得持续跳动。

阅读器图标的动效优先级：

1. 跟随手势。
2. 状态形变。
3. 墨迹填充。
4. 颜色变化。
5. 最后才允许循环运动。

## 7. 图标按钮容器

图标画板与触控区域分离：

| 使用场景 | 最小触控区 |
| --- | ---: |
| 常规按钮 | 44 x 44 |
| 紧凑工具栏 | 40 x 40 |
| 阅读器高频操作 | 44-48px |

- 默认容器可以透明，Hover/Press/Focus 时出现低对比度背景。
- 不把所有图标永久放进圆形按钮。
- 只有主要播放动作或真正的浮动主操作允许稳定填充容器。
- Press 作用于图标与容器整体，状态 Morph 只作用于图标内部。

## 8. 颜色

图标颜色只能来自：默认、次级、品牌强调、成功、警告、错误和 disabled 色。

- 选中优先使用统一品牌色，不随页面任意换色。
- 运行和选中必须同时具备形状区别。
- 深色模式重新校准线条对比度，不能只做颜色反转。
- 状态切换的颜色与形态同步完成。

## 9. 统一状态模型

```text
rest
  -> pressed
  -> activated / selected
  -> running
  -> completed
  -> error
  -> disabled
```

| 状态 | 主要表达 |
| --- | --- |
| Rest | 线性轮廓 |
| Pressed | 轻微压缩与加深 |
| Selected | 局部墨迹填充 |
| Running | 内部方向性流动 |
| Completed | 稳定完成形态 |
| Error | 路径断流与错误色 |
| Disabled | 降低对比度，无动效 |

每个图标只实现需要的状态，但页面不得创造新的同义状态。

## 10. 禁止项

- 普通点击后旋转图标。
- 把弹簧应用到所有图标。
- 相同状态在不同页面使用不同动画。
- 通过整体跳动表达成功。
- 无限呼吸缩放或多个图标同时循环。
- 未知进度使用高速旋转。
- 路径变化时线宽跳变或重心漂移。
- 选中态同时叠加放大、填充、光晕和位移。
- 因动效改变触控热区。
- Reduced Motion 下继续播放旋转和路径迁移。

## 11. 图标语言摘要

> Reader 图标是一套建立在统一网格上的温和线性符号。外轮廓稳定，内部结构承担状态变化；默认安静，触碰时轻微回应，选中时像墨迹填入，运行时沿既有路径流动，完成后收敛为静止形态。

四条识别规则：

1. 轮廓不跳。
2. 墨迹填充。
3. 路径流动。
4. 完成沉降。

品牌表达：

> 图标如字，静时清楚；触之有墨，动后归静。
