# 漫画 UI 独立 Demo 方案

日期：2026-10-02。状态：用于本轮可点击设计演示，新增布局及适配仍待用户评审。

- 不加入 TTS、文字替换、文字字体／排版、书内正文搜索、文字书签字段或 TXT 规则；不新增漫画发现、下载中心或单话／单行本版次选择页。

- [换源 V2](/Users/minliny/Documents/Reader/evidence/2026-09-30-manga-reading-design-baseline/source-switch-simple-proposal-v2-20260930.md:11)：从 0 候选持续发现、延迟排序、随时点选直接进入阅读。
- [共享书架最新确认](/Users/minliny/Documents/Reader/evidence/2026-09-30-manga-reading-design-baseline/bookshelf-type-filter-and-markers-20261001.md:141)：现有封面／列表内容、筛选、漫画位置、章节百分比与未知值表达已可用，不重列整页缺稿。
- [通用设计稿](/Users/minliny/Documents/Reader/evidence/2026-09-30-harmonyos-ui-reorganization/UI_DESIGN_SPEC.md:130)：复用搜索、详情、独立目录及 M04／M05 书源页面；其范围排除漫画，不能据此称漫画增量已获确认。

## 样例与证据边界

- 作品仅用 **山海纪行（虚构示例）**。作者、卷话标题、页位置、目录数量、示例来源与延迟都是设计 fixture，不是应用记录。
- 手机外固定说明“漫画 UI 设计示例 · 虚构作品与模拟数据”；演示加入、移除、换源、阅读位置仅更新内存样例，不读写真实书架或书源。
- 缺少来源美术时封面使用明确的空封面占位，阅读图使用标注页序的图占位；不借真实小说封面冒充漫画，不生成虚假内容截图。
- fixture 至少包含：卷组及其普通话子项、一个可读整卷；示例完整目录有 21 个可读条目，卷组标题不参与计数。
- 示例页总数与当前位置可靠已知；未知值规则沿用已确认 `*%`、`第 N 页` 和保留空白行规则，不以假的 0% 填充。
- 本地源码、浏览器渲染、交互 QA 和用户设计确认分别记录。Demo 通过不表示 Figma 同步、真实内容适配、HAP 或 HarmonyOS 验收通过。

## 共用视觉与滚动

- 日间：纸色 `#F8F4EC`、表面 `#FFFCF8`、墨色 `#1F1B17`、次文字 `#756F69`、强调深绿 `#1F3528`、细线 `#E7E0D5`。
- 次级页浮动顶栏高 52px、R18、左右 16px；返回触点 44px，标题 19/28px 居中。详情右侧等宽空位，不添加未定义“更多”。
- 标题、简介和目录用间距与细分隔组织，避免每个区块重复硬边框。正文左右 20px；段落间距以 24px 为基础。
- 浮动顶栏绘制表面内不透出底下文字；圆角外及间隙保持可见、可滑动。Scroll 覆盖页面，首尾避让放在滚动内容内。
- 两项主导航保留 196×68px 胶囊；选中深绿底、白色轮廓图标及标签，未选灰色图文；复用现有 Reader SVG。
- 详情操作 dock 高 68px、R24、左右 30px，主按钮高 48px／R16 弹性宽，次按钮 94px，间距 12px；轻阴影区别于正文。
- 安全区使用现有模拟设备运行时，保留 iPhone／Pixel、键盘、状态栏及手势行为；不硬编码截图时间，不编辑受保护运行时。
- 末行可滚到浮层上方；拖动按钮或图片超过点击阈值不得触发导航。输入复用键盘感知控件，弹层复用现有 BottomSheet。

## 按页方案与复用边界

| 页面／入口 | 已有基础 | 本轮内容与交互 | 确认边界 |
|---|---|---|---|
| 共享书架 | 用户已确认当前内容设计 | 沿用封面／列表、内容类型及来源筛选；漫画继续阅读展示话／卷与页位置，点击进阅读，书籍项进详情 | 已确认规则复用；虚构 fixture 只为新 demo |
| 统一搜索 | 通用搜索框、历史、结果卡、范围与来源分组 | 类型筛选 `全部／小说／漫画`；漫画结果标识、来源及最新话；点结果进详情，返回保留查询与滚动 | 漫画增量是候选，不另建漫画搜索系统 |
| 漫画详情 | 通用封面、简介、预览及操作区 | 居中“书籍详情”，清晰主次信息与三类目录条目；简介展开、完整目录、换源、阅读、入架／移除 | 本轮具体排版候选 |
| 完整目录 | S08／S09 已有独立目录、分组和搜索 | 共享卷组／可读整卷样式；搜索标题、切换顺序、定位当前项，选可读条目进阅读 | 并非重新补通用分组页面 |
| 阅读内目录 | 已确认 v7 六态中的目录面板 | 保留面板造型，换用共同目录层级与当前位置；选条目后关闭面板进入内容 | 基础六态保留，漫画层级增量待评审 |
| 换源 | V2 文字／动态规则及静态示意 | 首轮 0 项、陆续发现、耗时更新重排、随时点源直入阅读；保留返回上下文 | 简化方向有依据，完整视觉与起点策略待确认 |
| 书源管理／导入 | M04 原稿已有“漫画”chip；M05 已有文件／剪贴板／链接入口 | 复用现有 chip、筛选行与来源项；模拟筛选和启用；导入仅承接现有入口形态 | 不把已有漫画 chip 重列新增缺口；不新造书源工具 |
| 来源登录 | 复用来源登录容器 | 本轮不设计第三方登录网页，不新增漫画登录页 | 共用提示／反馈不计入本轮 |

## 漫画详情信息顺序

1. 浮动标题：返回／“书籍详情”／对称空位。
2. 封面与书名：84×122px 空封面；书名 24/34px、最多两行；作者 13/20px；漫画与来源类别保持既有标签角色。
3. 来源与阅读信息：当前来源及“换源”入口；最新话／卷；有可靠位置时显示原始条目标题及页位置，不强制把可读卷改成“话”。
4. 简介：默认三行、13/24px，展开／收起不改变内容身份。
5. 目录预览：标题“目录”、可靠可读条目数量、完整目录入口；展示 21 个示例可读条目及必要卷组标题。
6. 底部浮动操作：有位置“继续阅读”、无位置“开始阅读”；次操作按示例入架状态切换。确认与提示沿用共用形态，不新设计通用流程。
7. 从搜索或书架进入分别保留返回上下文；阅读返回原入口；详情不提供会返回自身的“书籍信息”菜单。

## 三处目录的共同语言

| 条目事实 | 视觉 | 点击含义 |
|---|---|---|
| 分组卷 | 44px 起的弱底标题行，14px 半粗体，展开箭头；子项缩进 16px | 只展开／收起，不进入阅读 |
| 普通章／话 | 58px 起的可读行，14/22px 标题，细分隔 | 进入该可读条目 |
| 可读整卷 | 同级可读行，辅助字“整卷可读”12/18px；保留来源原始卷名 | 直接进入整卷内容 |

- 标题含“卷”不构成分组证据；结构由 fixture 明确区分，正式需求由来源可靠数据决定。
- 统计分母只含可读条目，卷组标题不计章数；可靠目录结构才显示卷组数，不将卷组数与可读整卷数混为一项。
- 当前可读条目用浅绿底及“正在读”共同标记，不能只靠颜色；长标题自然增高，行高是最小值。
- 详情预览保留上述层级；完整目录允许搜索、顺序切换与当前项定位，搜索结果保留卷路径；阅读目录保留 v7 面板，不加入文字书签字段。
- 三处条目身份和当前位置一致；在目录选择目标后，返回详情的目录样式和示例位置相应更新。
- 不新增“单话版／单行本版”切换。搜索针对目录标题，不扩展到图片内文字或正文搜索。

## 漫画阅读六态与控件

- 手机竖屏六态继续采用已归档 v7 的沉浸态、控制栏、目录面板、设置面板、更多菜单、章末；不是重新计六个新页面。
- 用户最新漫画 scope 覆盖 v7 的文字功能标签：保留表面造型，把底部快捷操作改为 **目录／阅读方式／设置**。
- 目录：打开现有造型的目录面板；阅读方式：竖向连续／横向单图及适宽／完整图；设置：漫画阅读底色、亮度等已有漫画视觉控制。
- 沉浸态突出图占位，轻量页序；轻点内容显示控制栏；控制栏保留页位置／前后图／章末进入下一可读条目的漫画导航角色。
- 设置面板不放字体、字号、行距、替换或 TTS；“阅读方式”与“设置”分别承接图像观看方式和环境视觉，避免重复入口。
- 更多菜单只保留有依据的漫画动作，如换源／返回详情；不因为 v7 原稿出现文字功能就继续展示。
- 章末保留已有完成区域、下一可读条目与书末表达；不能把分组卷当下一章。Demo 到末项时不伪造后续内容。

## 横屏、平板、深色：同六态的版式候选

| 版式 | 内容区域 | 控件／目录／设置 | 状态 |
|---|---|---|---|
| 手机竖屏 | 保留 v7 的画面比例，使用图占位 | 原六态面板造型及新的漫画快捷标签 | 六态基础已有；新增标签为本轮范围修正 |
| 手机横屏 | 图像以可视区域完整显示，适宽模式允许原有滚动；图像不拉伸 | 紧凑顶栏与底部控件；目录／设置采用侧面板，建议宽 320px 且不超过画面 45%，面板内独立滚动 | 新版式候选，非既有竖屏稿验收 |
| 平板／宽屏 | 图像居中、等比显示；宽纸面避免图片被无限放大；不自动新增双页拼接 | 建议 ≥600px 使用 320–360px 侧面板；信息页内容最大 720px，保持既有层级与触点 | 新版式候选，断点和尺寸待实看评审 |
| 深色 | 建议炭色底 `#1C1E1A`、表面 `#282C25`、浅暖字 `#EAE7DE`、次字 `#ABA99F` | 减弱阴影，浅细边维持浮层边界；绿色选中保持可辨，图像本色不反转 | 新色板候选，不把底色选项当完整夜间稿已定 |

- 横屏／平板／深色均检查六态；改变容器布局，不另发明阅读业务状态。Demo 外部版式选择必须明确是设计控制，不伪装应用设置。
- 不旋转或替换受保护手机运行时；横屏和平板可使用 app-owned 排版预览承接，标为版式示意，不能声称模板已支持真实设备旋转。
- 深色应同时覆盖书架、搜索、详情、目录、换源及书源管理；先展示统一色板与主要表面，再记录实际覆盖矩阵，不以一个开关声称全套检查通过。

## 换源视觉与动态演示

1. 居中“更换书源”浮动顶栏，左返回、右停止／重新查找；正文小封面摘要含书名、当前来源及当前话／可读卷。
2. 稳定状态行：“正在查找 · 已发现 N 个”，右侧“延迟优先”；只用小动态图标，不遮挡已有来源。
3. 两行来源条目：来源名主行、最新话／卷副行；右侧固定 64px 延迟列，整行可点。当前来源已在摘要标明。
4. 首轮从 0 个开始；模拟候选陆续出现，有效延迟更新触发升序排序；相同延迟保持顺序，无有效值的正式设计应显示“检测中”并排后，不写 0ms；本 demo 的候选均使用已知模拟耗时。
5. 按下、拖动／滚动、键盘焦点停在来源行时暂缓重排；数据与计数仍更新，结束后自动重排并保持浏览位置。
6. 点选绑定来源身份，随时直接尝试打开；不等整轮结束，不放匹配评分、位置预览、图片对比或二次确认。
7. 找到可靠对应话／可读卷时进入该条目；从其开头进入仍是 V2 待确认策略。无对应时进入同一目录的目标选择，不按序号硬套或默默跳第一话；这是 V2 保留策略，本 demo 未模拟无对应的来源。
8. 停止保留结果；重新查找保留列表与位置，旧延迟标为重测中。返回后旧轮次结果不继续提交换源。
9. 延迟示例表达“目标首图可显示”的同阶段耗时，不混用 ping、搜索或完整下载；全部为模拟值，不访问真实来源。

## Demo 最小检查路径

- 书架 → 搜索 → 漫画详情 → 返回：筛选、查询和滚动保留；封面占位不触发浏览器原生拖图。
- 详情 → 完整目录：卷组只展开，可读整卷和普通话均能进入阅读；21 个可读条目的末项能滚过底部浮层。
- 阅读 → 控制栏 → 目录／阅读方式／设置／更多 → 返回正文；章末可进入下一可读条目，样例位置跨三处目录一致。
- 换源：实际演示 0 → 增量 → 重排、查找中点选、停止／再查找与返回保留；无预览或确认步骤。
- 搜索／书源漫画 chip、加入／移除和来源启用均为可点击内存示例；无需执行系统文件选择或真实书源导入。
- 日间、深色、横屏版式与平板版式逐态记录哪些画面已实看；检查居中标题、窄宽长标题、卷层级、末端避让及图占位比例。
- 根 agent 负责实现和浏览器 QA；本文件只提供方案。未见到的画面不得登记已完成，用户评审前不得写成最终设计。
