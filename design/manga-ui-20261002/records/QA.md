## 发现与修正

| 现象／条件 | 定位与处理 | 当前边界 |
|---|---|---|
| 目录输入／range更新重建DOM | 局部组件身份每render变化；改为无hooks builder调用 | 连续输入、进度与亮度控制通过 |
| 停止后继续入候选；返回后冻结排序 | 保留定时器及焦点状态；清轮次、复位冻结、已发现项继续更新 | 停止／重查／排序／直读通过 |
| 本话末和整卷末目标不一致 | 文案和按钮共用下一可读条目，无下一条显示书末 | 第20话与番外卷边界通过 |
| 定位只展开不滚动 | 按稳定条目ID滚所属目录容器；阅读内目录打开自动定位 | 当前条目可见 |
| 导入点击在键盘关闭时丢失 | blur引起表面移位；提交pointerdown保留焦点直到click完成 | 内存导入样例可点击，非真实导入 |
| 目录搜索影响详情和平板目录 | 区分预览与固定侧目录的搜索范围 | 两处完整层级恢复 |
| 返回滚动位置清零 | 卸载后的节点scrollTop清零覆盖缓存；导航前保存且移除cleanup读取 | 208→208通过 |

检查脚本曾有两类自身误判：卷组可访问名称含空格，以及“山”同时匹配山海／远山；均修正选择器或查询后通过。返回位置检查最初在自动滚动按钮前取值，改为进入目录时的实际位置。初次弹层截图在入场动画完成前抓取，后续改为稳定后截图，不将过渡帧登记为静态画面。
