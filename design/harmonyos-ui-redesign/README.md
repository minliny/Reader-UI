# 墨纸青松 2.0 UI 设计参考

本目录存放 Reader 的视觉与交互设计参考指导稿，供跨端实现和后续迭代查阅。目录内容不是运行时构建输入，也不替代 `theme/registry.json` 与 `contracts/` 作为正式令牌和协议的唯一维护源。

## 文件清单与打开方式

- `reader-harmonyos-ui-redesign.html`：主参考指导 Demo，包含主要页面、主题、组件和动效示例。直接用浏览器打开即可预览。
- `implementation-plan.md`：工程实施参考文档，记录设计约束、组件落位和实施时的核对依据。
- `demos/reader-bookmark-ribbon-demo.html`：阅读器纸顶丝带书签交互 Demo。
- `demos/reader-bookmark-motion-demo.html`：书签动效对比 Demo。
- `demos/reader-control-refined-demo.html`：阅读器控制栏精修 Demo。
- `demos/reader-control-progress-compare.html`：控制栏进度方案对比 Demo。
- `demos/reader-control-logic-diagram.html`：控制栏交互逻辑图 Demo。
- `demos/reader-playback-compare-demo.html`：自动翻页与朗读播放会话对比 Demo。

所有 HTML 参考稿都可以直接用浏览器打开。部分样式依赖外链预览脚本，离线环境可能出现样式降级。

## 相对冻结初稿的已确认设计收口修订

1. **非正文字体统一**：全应用所有非正文界面，包括顶栏标题、书名、弹窗、副标题、设置与搜索，统一使用全字库思源黑体 UI 系列。文学字体（思源宋体、霞鹜文楷、朱雀仿宋等）仅用于阅读正文、阅读章节大标题（随正文选中字体联动）与外观字体预览。
2. **按钮与容器几何统一**：独立动作按钮与悬浮顶底栏统一全胶囊矩阵（`r=999`），内容卡片（`r=14`）、输入框（`r=10`）、分段器轨道（`r=12`）、小徽章（`r=5~6`）保持圆角矩形。
3. **设置页结构统一**：宽屏设置左栏菜单与窄屏设置首页同源驱动。仅设置首页与宽屏左栏保留 `28×28` 导航图标，设置子页配置项统一无左侧图标，并使用标准卡片、分段器和下拉框规格。
4. **书架默认视图与列表排布**：默认视图统一为 `list`。列表卡片封面与右侧 5 层信息等高顶底对齐，`···` 移至第 1 行右上角，进度条与百分比合一，本地书隐藏无效“最新章节”。
5. **搜索栏与搜索历史**：单层清空图标覆盖所有场景，主搜索框与搜索钮等高，历史标签采用全胶囊和均匀间距，面板高度按内容自适应。

## 书源管理 v9 收口

- 书源管理、导入书源、书源订阅、分组总览与详情、书源登录共用主 Demo 的导航与反馈。手机从设置进入，平板在设置右侧展开。书源列表可按搜索、分组和类型缩小范围，状态计数与可见结果一致。更多菜单提供订阅、分组、批量检测和全部导出。
- 单源、批量、整组及导入前检测使用同一组分层结果。可按搜索或发现选择检测深度，搜索支持自定义测试词。批量报告可钻取到单源重新检测，结果与计数随之更新。
- 三步导入支持本地文件、在线链接、粘贴 JSON。校验阶段锁定不支持的类型，检测失败的条目可由用户重新勾选并保留报告。提交结果分别列出新增、更新与静态过滤数量，继续导入时重置本轮表单。
- 订阅支持管理、启停和检查更新。差异预览中保留本地的冲突不计入应用数量。应用时写入已选书源、检测报告或净化规则。分组支持批量移动、移出和整组启停，删除分组保留成员。
- 登录页展示网页会话和验证状态。完成后保存会话并复测到 L2，停用书源时撤销会话，清除登录态时同时清除旧检测报告。

主 Demo 的分层检测与登录使用随稿示例数据。选取的本地文件会在浏览器中读取，在线导入和订阅可使用示例链接，也可加载浏览器允许跨域读取的 HTTP(S) JSON。
